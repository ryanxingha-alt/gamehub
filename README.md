Project Overview

GameHub is a modern, dynamic web-based digital game store where users can browse, explore, and view different games. It is designed with an interactive UI and smooth user experience, similar to real-world platforms like Steam or Epic Games.

🚀 Features
🎯 Browse different games
🔍 Game details and descriptions
🖼️ Attractive UI with modern design
⚡ Fast and responsive layout
🎨 Stylish animations and effects
📱 Mobile-friendly design
🛠️ Technologies Used
HTML5 – Structure of the website
CSS3 – Styling and layout
JavaScript – Interactivity and dynamic features
